## ✨ About The Project

This is my **personal portfolio website**, created to present my professional profile, technical skills, projects, and contact information in a modern and interactive way.

The website is designed with a clean visual style, smooth animations, responsive layouts, and an easy-to-navigate interface.

It serves as a central place where recruiters, companies, clients, and other developers can learn more about my work and technical background.
